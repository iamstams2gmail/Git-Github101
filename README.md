# 🎂 Happy Birthday — แอนิเมชันวันเกิดเต็มจอด้วย tkinter by chaiwat

โปรแกรมอวยพรวันเกิดแบบเต็มจอ เขียนด้วย Python + tkinter อยู่ในไฟล์เดียว (`happy_birthday.py`)
ไม่ต้องติดตั้งไลบรารีเพิ่ม ไม่มีไฟล์รูปหรือฟอนต์ประกอบ เหมาะสำหรับเปิดบนจอหรือโปรเจกเตอร์ในงานวันเกิด

![ตัวอย่างหน้าจอโปรแกรม](screenshot.png)

> ภาพตัวอย่างเป็นเฟรมที่ประมาณวินาทีที่ 6 หลังเปิดโปรแกรม ตัวอักษรบนเครื่องจริงอาจต่างจากภาพ
> เพราะโปรแกรมเลือกฟอนต์ตามที่มีในเครื่อง (เช่น Segoe Print บน Windows)

## ✨ Features

| | รายละเอียด |
|---|---|
| 🔠 **ตัวอักษร Happy Birthday** | ตกลงมาทีละตัวแบบเด้ง มีประกายตอนแตะพื้น แล้วลอยขึ้นลงเป็นคลื่น มีแสงเรืองและสีรุ้งที่เปลี่ยนไปเรื่อยๆ |
| 🎈 **ลูกโป่ง** | ลูกโป่งหลายสีลอยขึ้นจากด้านล่าง ตัวลูกโป่งส่ายไปมาและเชือกแกว่งตาม |
| 🎊 **คอนเฟตติ** | กระดาษสีหมุนพลิกตกลงมาทั่วจอตลอดเวลา |
| 🎆 **พลุ** | ระเบิดเองเป็นระยะ และคลิกจุดเองได้ |
| 🎂 **เค้กวันเกิด** | เค้กสองชั้นมีครีมย้อย เทียน 5 เล่ม เปลวไฟสั่นไหวเหมือนจริง |
| ⌨️ **ข้อความอวยพร** | พิมพ์ขึ้นมาทีละตัวอักษรใต้คำว่า Birthday แก้ข้อความเองได้ |
| 🖥️ **เต็มจอ** | ปรับขนาดทุกอย่างตามความละเอียดจออัตโนมัติ |
| 🤫 **ปุ่มปิดลับ** | ไม่มีปุ่มปิดให้เห็น ต้องรู้ตำแหน่งลับเท่านั้น (ดูด้านล่าง) |

## 🖱️ การควบคุม

### คลิกเมาส์ได้มั้ย? — ได้ครับ

| คลิกที่ | ผลลัพธ์ |
|---|---|
| ตัว **y** ตัวสุดท้ายของคำว่า "Birth**day**" | **ปิดโปรแกรม** (ปุ่มปิดลับ) |
| ตำแหน่งอื่นบนจอ | จุดพลุตรงจุดที่คลิก |

### ปุ่มคีย์บอร์ด

| ปุ่ม | ผลลัพธ์ |
|---|---|
| `Space` | เล่นแอนิเมชันใหม่ตั้งแต่ต้น (ตัวอักษรตกลงมาใหม่) |
| `Esc` | ทางออกฉุกเฉิน กันติดหน้าจอเต็มจอ (ปิดได้ ดูหัวข้อปรับแต่ง) |

> 💡 **ปุ่มปิดลับ:** โปรแกรมเปิดแบบเต็มจอ จึงไม่มีแถบหัวหน้าต่างหรือปุ่ม ✕
> ให้คลิกที่ตัว **y** ท้ายคำว่า **Birthday** ซึ่งไม่มีอะไรบอกบนจอเลย คนอื่นที่คลิกเล่นจะเห็นแค่พลุ

## ▶️ วิธีรัน

### 1. ติดตั้ง Python (ถ้ายังไม่มี)
ต้องใช้ **Python 3.8 ขึ้นไป** ดาวน์โหลดได้ที่ <https://www.python.org/downloads/>
บน Windows ให้ติ๊ก **"Add Python to PATH"** ตอนติดตั้ง

### 2. รันโปรแกรม

**Windows**
```bat
python happy_birthday.py
```
หรือดับเบิลคลิกไฟล์ `happy_birthday.py` ได้เลย

**macOS / Linux**
```bash
python3 happy_birthday.py
```

### ถ้าขึ้นว่า `No module named 'tkinter'`
tkinter ติดมากับ Python จาก python.org อยู่แล้วบน Windows และ macOS ส่วน Linux ต้องติดตั้งเพิ่ม:

```bash
sudo apt install python3-tk      # Ubuntu / Debian
sudo dnf install python3-tkinter # Fedora
```

### (ไม่บังคับ) ทำเป็นไฟล์ .exe เปิดได้โดยไม่ต้องลง Python
รันคำสั่งนี้บนเครื่อง Windows ที่มี Python:

```bat
pip install pyinstaller
pyinstaller --onefile --noconsole happy_birthday.py
```
จะได้ไฟล์ `dist\happy_birthday.exe` ที่คัดลอกไปเปิดบนเครื่องอื่นได้ทันที

## 🛠️ ปรับแต่ง

แก้ค่าได้ที่ส่วนบนสุดของไฟล์ `happy_birthday.py`:

```python
LINE1 = "Happy"
LINE2 = "Birthday"            # ปุ่มปิดลับ = ตัวอักษรสุดท้ายของบรรทัดนี้
MESSAGE = "Wishing you a year full of love, laughter & cake!"
ALLOW_ESC = True              # False = ปิดได้ทางตัว y เท่านั้น
BALLOON_COUNT = 14            # จำนวนลูกโป่ง
CONFETTI_COUNT = 150          # จำนวนคอนเฟตติ (ลดลงถ้าเครื่องกระตุก)
CANDLES = 5                   # จำนวนเทียนบนเค้ก
```

- **ใส่ชื่อเจ้าของวันเกิด:** แก้ `MESSAGE` เช่น `"Happy Birthday, Nong May!"` (ไม่แนะนำให้ใส่อีโมจิ เพราะ tkinter บางเวอร์ชันแสดงไม่ได้)
- **เปลี่ยนสี:** แก้ `BG_STOPS` (พื้นหลัง), `BALLOON_COLORS` และ `CONFETTI_COLORS`
- **เครื่องช้าหรือกระตุก:** ลด `CONFETTI_COUNT` และ `BALLOON_COUNT` ลง

> ⚠️ ถ้าเปลี่ยน `LINE2` ปุ่มปิดลับจะย้ายไปอยู่ที่ **ตัวอักษรสุดท้าย** ของข้อความใหม่
> และถ้าตั้ง `ALLOW_ESC = False` ควรทดลองคลิกตัวปิดลับให้แน่ใจก่อนใช้งานจริง
